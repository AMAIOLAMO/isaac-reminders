# TOO MANY REMINDERS
![Thumbnail](https://github.com/AMAIOLAMO/isaac-reminders/blob/main/reminders_thumbnail.gif)

A mod for gamers who have gold fish memory :)

The official steam page is [here](https://steamcommunity.com/sharedfiles/filedetails/?id=3610902393)

## Support For languages
Currently Supported languages: English, Chinese, Russian.

To switch language, use Mod Config Menu Pure.
It should be in the section called "Reminders" and subsection "General".
